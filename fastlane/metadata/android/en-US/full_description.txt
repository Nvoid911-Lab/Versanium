Versanium is an independent, unofficial Android browser derived from Titanium Browser for Android, focused on comfortable browsing across smartphones and desktop-style environments, including Samsung DeX.

Versanium inherits its Chromium-based browser architecture and extension support from Titanium Browser. Manifest V2 (MV2) extensions are supported by the current implementation.

Install extensions from:
- Chrome Web Store
- Opera Add-ons
- Microsoft Edge Add-ons

Local CRX/ZIP installation is available through Titanium Extension for Android. Unpacked extensions can be loaded for testing through chrome://extensions by enabling Developer mode and choosing Load unpacked.

Titanium Extension for Android is an upstream component, not a Versanium-developed extension. It provides modular features such as external download manager integration, enhanced dark mode, and additional privacy options:
https://github.com/jqssun/android-titanium-extension

To allow an extension in Incognito (OTR), open Manage extensions, choose Details, and enable Allow in Incognito. Only enable trusted extensions.

Versanium additions include F11 fullscreen controls and independent smartphone/desktop-environment default and site zoom settings. Compatibility with individual Android desktop environments may vary.

WebRTC IP Policy is available in Settings under Privacy and security. If the default policy prevents a required connection, review Default public interface only or Default and their privacy implications.

Browser pages are available through chrome://chrome-urls; experimental settings through chrome://flags.

Published Versanium releases target arm64-v8a. Experimental test APKs are distributed as Actions artifacts, not formal releases.

Versanium is not maintained, endorsed, or supported by the upstream Titanium Browser developers. It does not replace Titanium Browser.
